Two drives,
one set of files.

rclone for personal use keeps a folder on my computer and my Google Drive in step, so a file added in one place shows up in the other.

What it does
Copies new and changed files between a folder on my computer and a folder in my Google Drive. It runs on a schedule, on my own computer only.
What it can see
Files in my own Google Drive, after I sign in and grant access. Nothing is sent to a server of mine, because I don’t run one.
Who uses it
Only me. This is a personal tool, not a public product. It has no sign-ups, no other users, and no analytics.

The details of how information is handled are in the privacy policy.
